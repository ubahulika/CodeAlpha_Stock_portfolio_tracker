# Stock Portfolio Tracker 📈

 📌 Project Description
This project allows users to:
1. Enter stock names and quantities
2. Calculate total investment value
3. Store stock prices using a Python dictionary
4. Save the final result into a text file

The program uses basic Python concepts like:
1. Dictionary
2. Loops
3. Conditional statements
4. User input/output
5. File handling

 🚀 Features
1. User-friendly console interaction
2. Calculates investment value instantly
3. Supports multiple stock entries
4. Saves portfolio summary to a .txt file

 🛠️ Technologies Used
1. Python

 📂 Example Stocks Used
1. AAPL
2. TSLA
3. GOOG
4. MSFT
5. AMZN

 ▶️ How to Run
1. Install Python
2. Download the project
3. Open terminal or command prompt
4. Run the file using: stock_portfolio_tracker.py
